# Teaching roadmap: Cloud E-Commerce

1. **Git and application basics**: clone, branching, PRs, React, FastAPI, HTTP, and PostgreSQL. Demo: browse products and place a demo order.
2. **DevOps**: Docker, Compose, Nginx, CI using GitHub Actions, container scanning, release tags, and CD.
3. **Cloud-native**: Kubernetes Deployments, Services, Ingress, ConfigMaps, Secrets, persistent storage, Terraform and Argo CD in a separate lab cluster.
4. **Machine learning**: export anonymized synthetic order histories; train demand forecasting and recommendation models away from the VPS.
5. **MLOps**: dataset versioning, MLflow tracking, model validation, registry, automated batch training, monitoring and retraining.
6. **GenAI**: RAG over synthetic product FAQs and store policies; vector retrieval; evals; a shopping assistant backed by external LLM APIs.
7. **Agentic AI**: inventory recommendations, supplier simulation, tool calling, human approval, audit logs, permissions, and agents evaluated against test scenarios.

**Important**: phases 4–7 are a roadmap, not components already implemented in this starter.
